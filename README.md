# نظام إدارة الطلاب - Student Management System

تطبيق شامل لإدارة الطلاب يتضمن الحضور والغياب، المدفوعات، التقارير، والاختبارات مع تكامل إشعارات واتساب.

## الميزات الرئيسية

✅ تسجيل وإدارة الطلاب
✅ تقسيم الطلاب (ذكور/إناث/شعب)
✅ تتبع الحضور والغياب اليومي
✅ إدارة المدفوعات والأقساط
✅ تقييم السلوك والملاحظات
✅ إدارة الاختبارات (أسبوعية/شهرية/نصفية)
✅ تقارير سنوية شاملة
✅ إشعارات واتساب تلقائية
✅ طباعة التقارير PDF
✅ لوحة تحكم شاملة

## التثبيت والتشغيل

### المتطلبات
- Node.js v18+
- MongoDB
- Twilio Account

### البدء

```bash
# استنساخ المستودع
git clone https://github.com/deaia/Edu-.git
cd Edu-

# تشغيل الخادم
cd backend
npm install
npm run dev

# تشغيل الواجهة الأمامية
cd frontend
npm install
npm start
```
