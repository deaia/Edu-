# 📱 Edu Management System - Mobile App

تطبيق جوال لنظام إدارة التعليم مع Material UI وواجهات سهلة الاستخدام.

## ✨ المميزات

- 🏠 لوحة التحكم الرئيسية مع إحصائيات
- 👥 إدارة الطلاب (عرض وتعديل)
- 📋 تسجيل الحضو�� والغياب
- 💰 إدارة الدفوعات
- 📝 الامتحانات والدرجات
- 📊 التقارير والإحصائيات
- 🇸🇦 دعم اللغة العربية
- 🎨 واجهة جميلة مع Material Design

## 🛠️ التقنيات المستخدمة

- **React Native** - لتطوير التطبيق
- **TypeScript** - لسلامة الأنواع
- **React Navigation** - للتنقل بين الشاشات
- **Material UI** - لواجهات جميلة
- **Axios** - لطلب API
- **AsyncStorage** - لتخزين البيانات محليا

## 📦 التثبيت

### المتطلبات
- Node.js (v14 أو أحدث)
- React Native CLI
- Android Studio أو Xcode

### خطوات التثبيت

1. انسخ المشروع:
```bash
cd mobile
```

2. ثبت المكتبات:
```bash
npm install
```

3. ثبت المتطلبات المحلية:
```bash
npx react-native doctor
```

## 🚀 التشغيل

### تشغيل على Android
```bash
npm run android
```

### تشغيل على iOS
```bash
npm run ios
```

## 📱 الشاشات الرئيسية

### 1. الصفحة الرئيسية (Home)
- عرض الإحصائيات الأساسية
- عدد الطلاب
- الحاضرون اليوم
- إجمالي الدفوعات
- متوسط الحضور

### 2. إدارة الطلاب (Students)
- عرض قائمة الطلاب
- تفاصيل الطالب الكاملة
- تعديل وحذف
- إضافة طالب جديد

### 3. الحضور والغياب (Attendance)
- تسجيل الحضور
- عرض السجلات
- احصائيات الحضور

### 4. الدفوعات (Payments)
- تسجيل الدفعات
- عرض السجلات
- تتبع الرسوم المتبقية

### 5. الامتحانات (Exams)
- تسجيل الامتحانات
- عرض الدرجات
- احصائيات الأداء

### 6. التقارير (Reports)
- رسوم بيانية
- احصائيات شاملة
- تقارير الأداء

## 🔌 الاتصال بـ Backend

التطبيق يتصل بـ Backend على:
```
http://localhost:5000/api
```

تأكد من أن Backend يعمل قبل تشغيل التطبيق.

## 📝 أمثلة على الاستخدام

### جلب الطلاب
```typescript
import { studentsAPI } from './services/api';

const students = await studentsAPI.getAll();
```

### تسجيل حضور
```typescript
import { attendanceAPI } from './services/api';

await attendanceAPI.record({
  studentId: '60d5ec49f1b2c72b8c8e4a1a',
  status: 'present',
  note: 'حاضر'
});
```

## 🔐 الأمان

- استخدم متغيرات البيئة للمعلومات الحساسة
- خزن tokens في AsyncStorage بأمان
- استخدم HTTPS في الإنتاج
